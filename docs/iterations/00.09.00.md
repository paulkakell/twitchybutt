## Operator examples

Run before staging/private-beta deployment:

```sh
APP_ENV=staging APP_URL=https://creator.example APP_DEBUG=false \
APP_KEY='<configured locally>' DB_CONNECTION=pgsql \
CMS_PAYMENTS_ENABLED=false CMS_RESTRICTED_PUBLISHING_ENABLED=false \
python3 scripts/deployment_preflight.py
```

Generate an opt-in support snapshot. The exporter uses an allowlist and excludes keys, passwords, tokens, media, reports and database contents:

```sh
python3 scripts/support_diagnostics.py > support-diagnostics.json
```

Do not attach application logs, database dumps, media, mail bodies, identity records or secrets to public issues.
